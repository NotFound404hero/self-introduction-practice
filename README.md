# self-introduction-practice

## 概要

COACHTECH 教材 Tutorial 5-1−7「HTMLの基礎 ハンズオン演習」で学んだ成果物です。学習の一環として私の自己紹介ページを作成しております。

## 使用技術

- HTML5、GitHub、VSCode、Google Chrome

## 学んだこと

・Webページの仕組み<br>
・コマンド入力<br>
・コードの管理<br>
・環境構築はハードも大切(デスク、チェア、外部モニタなど)<br>
　床に座っての学習は腰が辛い<br>
・自宅、スタバ、図書館よりもネカフェが優秀<br>
・教材だけでは自分の意図した通りに表示できない<br>

## 動作確認

作成したHTMLファイルをブラウザで開き、<br>
・文字化けしていないか<br>
・段落は正しく表示されているか<br>
・入力欄に入力可能か<br>
・必須入力箇所に未入力の場合にエラー表示が正しくされるか<br>
・リンクは正しく機能し、リンク先へページが飛ぶか<br>
・画像は正しく表示されているか<br>
・脳内CPU、脳内メモリ、脳内ストレージは記憶を保持し、正しく機能しているか<br>
などを確認しています。<br>
