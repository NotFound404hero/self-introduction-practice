# self-introduction-practice

## 概要

COACHTECH 教材 Tutorial 5-1−7「HTMLの基礎 ハンズオン演習」で学んだ成果物です。学習の一環として私の自己紹介ページを作成しております。

## 使用技術

- HTML5、GitHub、VSCode、Google Chrome

## 学んだこと

Webページの仕組み、コマンド入力、コードの管理、
床に座っての学習は腰が辛い

## 動作確認

作成したHTMLファイルをブラウザで開き、
・文字化けしていないか
・段落は正しく表示されているか
・入力欄に入力可能か
・必須入力箇所に未入力の場合にエラー表示が正しくされるか
・リンクは正しく機能し、リンク先へページが飛ぶか
・画像は正しく表示されているか
などを確認しています。
